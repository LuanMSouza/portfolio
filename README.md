## 📋 Sobre

Site pessoal para apresentar projetos, habilidades e trajetória como desenvolvedor full stack. Desenvolvido com foco em performance e design limpo.

## 🚀 Como Rodar

```bash
git clone https://github.com/LuanMSouza/portfolio
cd portfolio
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).
